# Тогуз Коргоол — онлайн-игра с другом

## Как это работает
- `server/` — маленький сервер-ретранслятор (Node.js + WebSocket). Он НЕ знает правил игры,
  просто соединяет двух игроков по коду комнаты и пересылает ходы между ними.
- Клиент (сама игра) при каждом ходе шлёт на сервер `{type:'move', idx}`, сервер пересылает
  это второму игроку, и оба клиента у себя одинаково просчитывают результат — правила у обоих
  одни и те же (`src/rules.js`), так что доски не расходятся.

## Шаг 1 — задеплоить сервер (один раз)
Нужен любой бесплатный хостинг, который держит постоянное соединение (обычный статический
хостинг типа GitHub Pages не подойдёт — нужен именно процесс Node.js).

Самый простой вариант — **Render.com** (есть бесплатный план):

1. Зарегистрируйтесь на render.com, подключите свой GitHub.
2. Залейте папку `server/` в отдельный репозиторий на GitHub (или весь проект целиком).
3. В Render: **New → Web Service** → выберите репозиторий.
   - Root directory: `server` (если грузили весь проект целиком)
   - Build command: `npm install`
   - Start command: `npm start`
   - Instance type: Free
4. После деплоя Render даст адрес вида `https://your-app.onrender.com`.
   Для WebSocket его нужно использовать с `wss://` вместо `https://`:
   `wss://your-app.onrender.com`

Альтернативы с тем же принципом: **Railway.app**, **Fly.io**, любой свой VPS
(`npm install && npm start`, открыть порт).

> Бесплатный план Render "засыпает" без активности — первое подключение может занять
> 20–30 секунд, пока сервер "просыпается". Это нормально.

## Шаг 2 — играть
1. Откройте `toguz-korgool.html` (у обоих игроков — можно просто прислать файл другу,
   или выложить его тоже куда-нибудь и открыть по ссылке).
2. Нажмите **🌐 Играть онлайн**.
3. Игрок 1: вставляет адрес сервера (`wss://...`), жмёт **Создать** — получает код комнаты.
4. Игрок 1 отправляет другу код комнаты (любым способом — просто текстом).
5. Игрок 2: вставляет тот же адрес сервера, вводит тот же код, жмёт **Войти**.
6. Как только оба подключены — игра стартует, каждый ходит только в свой ход.

## Локальная проверка (без хостинга)
Если хотите проверить у себя на компьютере, что всё работает, прежде чем куда-то деплоить:

```bash
cd server
npm install
npm start
```

Сервер поднимется на `ws://localhost:8080`. Откройте игру в двух вкладках браузера
на одном компьютере и в обоих используйте адрес `ws://localhost:8080` — сможете
сыграть сами с собой, чтобы убедиться, что синхронизация работает.

## Развитие проекта
- `src/rules.js` — чистая логика правил, без рендера.
- `src/main.js` — PixiJS-рендер, drag-анимация, сетевой клиент.
- `server/server.js` — релей-сервер.

`npm run dev` — локальная разработка с hot-reload (Vite).
`npm run build` — собрать обратно в один самодостаточный `dist/index.html`.
